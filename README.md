# Typing War | 멀티플레이 타이핑 게임

두 플레이어가 같은 방에 들어가 키보드로 경쟁하는 **Java Swing · TCP 소켓** 기반 팀 프로젝트입니다. 게임 화면뿐 아니라 로그인, 대기실, 방 참가처럼 여러 클라이언트가 상태를 공유하는 흐름을 구현하는 프로젝트였습니다.

## 내가 작업한 부분

초기 Swing GUI 틀을 만들고, 팀 통합본에서 클라이언트 두 개를 띄워 로그인 → 방 생성 → 두 번째 사용자 참가 → 준비 상태 변경을 확인했습니다. 대기실에서 테스트 메시지도 주고받았습니다.

## 어떻게 동작하나요?

1. Swing 클라이언트가 로그인과 방 참가 요청을 TCP로 서버에 보냅니다.
2. 서버가 방과 플레이어 상태를 관리하고, 같은 방의 클라이언트가 상태를 반영합니다.
3. 클라이언트와 서버는 공통 `GameMsg` 형식으로 요청과 상태를 구분합니다.

**확인 범위** · 두 클라이언트의 대기실 흐름까지 확인했습니다. 이 테스트로 경기 완료나 관전 기능까지 검증한 것은 아닙니다. 이 페이지는 공개 소개본이며, 팀 저장소의 소스·개인 브랜치·ZIP은 포함하지 않습니다.
